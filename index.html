Hoca ve konu düğmeleri, kendi YouTube Data API anahtarını girersen videoları uygulama içinde listeler. Anahtar girmezsen güvenli biçimde YouTube aramasını açar.

Henüz test edilmedi.

file:// notu: dosyayı doğrudan açtığında tarayıcı normal ağ isteklerini engelleyebiliyor. Uygulama bu durumu algılayıp isteği JSONP yöntemiyle gönderiyor; ek bir şey yapman gerekmez.

Güvenlik: API anahtarı uygulama dosyasına gömülü değildir. Kendi anahtarını girersen yalnız bu cihazda tutulur, JSON yedeğine ve bulut senkronuna eklenmez. Anahtarı Google Cloud tarafında alan adı ve API ile sınırlandırman önerilir.
