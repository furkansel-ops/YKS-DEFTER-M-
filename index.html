Henüz test edilmedi.

file:// notu: dosyayı doğrudan açtığında tarayıcı normal ağ isteklerini engelleyebiliyor. Uygulama bu durumu algılayıp isteği JSONP yöntemiyle gönderiyor; ek bir şey yapman gerekmez.

Gömülü anahtar: kişisel kullanım için uygulamada hazırdır. Uygulama klasörünü başkalarıyla paylaşırsan anahtar da paylaşılmış olur. Kendi anahtarını kullanmak istersen console.cloud.google.com üzerinden YouTube Data API v3 anahtarı oluşturup buraya girebilirsin. JSON yedeğine API anahtarı eklenmez.
