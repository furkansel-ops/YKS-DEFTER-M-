# YKS Defterim — GitHub Pages

Bu paket doğrudan GitHub Pages için hazırlanmıştır.

## Bu sürümde
- Ana ekran sadeleştirildi.
- Sınava kalan gün + günlük istatistikler + seriler tek özet kartında toplandı.
- Günün özeti / Gün ekranı kısayolları kompakt hale getirildi.
- Haftalık hedef bölümü açılır bölüme taşındı.
- Hızlı soru girişi sadeleştirildi.
- Kart, gölge, boşluk ve tipografi sistemi tutarlı hale getirildi.
- Animasyonlu arka plan sakinleştirildi.
- Firebase / Google giriş / Firestore senkronizasyonu korunmuştur.
- PWA önbellek sürümü yenilenmiştir.

GitHub deposunun kök dizinine bu paketteki dosyaları yükleyin.
